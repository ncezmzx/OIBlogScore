# 算法审查参考

以下反例是校对用见证，不是看到关键字即可套用的结论。先核对题目约束和代码路径。`--category` 使用同名的启发式标签，不等于完整知识分类。

| 类别 | 审查要点 | 最小见证方向 |
|---|---|---|
| dp | 状态充足性、初值、可达性、遍历顺序 | 0/1 背包容量 2，只有重量 1 价值 1 的物品；正向更新错误地得到 2 |
| graph | 权值前提、连通性、重边、不可达与断图 | s→a=1，s→b=2，b→a=-2；定点版 Dijkstra 不成立 |
| greedy | 交换是否合法且不降低目标 | 区间 [0,9]、[1,2]、[3,4]；按起点选不是最大不重叠数 |
| strings | 空串约定、重叠匹配、分隔符冲突 | `aaaa` 中 `aa` 有三个重叠起点 |
| number-theory | 模逆存在条件、符号、乘法范围 | 2 在模 4 下没有逆元 |
| data-structures | 半开区间与下标、延迟标记合成、操作顺序 | 对同一区间先加后覆盖，不得保留旧加法 |
| search | 单调性、哨兵与无解、循环终止 | 谓词恒假时边界不能当作可行答案 |
| flow | 反向边、残量、增广后重新可达 | 二分图 L1→R1/R2、L2→R1；先取 L1→R1 后需撤销重配 |
| geometry | 共线、重复点、精度、坐标范围 | (0,0)、(1,1)、(2,2) 不能组成严格凸角 |
| counting | 空对象、带标号与无标号、重复计数 | 多重集 aab 仅有 3 个不同排列，不是 6 |
