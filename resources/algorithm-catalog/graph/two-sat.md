# 2-SAT：蕴含图与赋值方向

## 问题模型

布尔变量的二文字析取合取式；单位子句可用重复文字编码。问题包含判定及可选赋值。

## 算法原理

每条 `(a∨b)` 加 `¬a→b` 与 `¬b→a`。计算 SCC；排除任何变量与其反文字同 SCC，然后按缩点拓扑序选择较晚分量内文字为真。

## 成立条件

拓扑序明确为边从早指向晚；图必须包含互为逆否的两条边。变量 ID 与取反映射一致。

## 关键不变量

赋真集合对所有蕴含边封闭，且每对互补文字恰一真。否定映射把分量配对，并逆转缩点边方向。

## 证明路线

必要：同 SCC 的 x 与 ¬x 互相强迫。不矛盾的情形，设 u 真 v 假但 u→v，则 `¬u < u ≤ v < ¬v ≤ ¬u`（分量编号）矛盾，证明充分。

## 复杂度推导

2n 顶点、至多 2m 条边，构图、SCC 与显式拓扑均 O(n+m) 时间与空间；不需传递闭包。

## 错误与反例

子句 `(x∨x)` 强制 x 真；错误的拓扑方向会构造 x 假，即使判定可满足正确。

## 性质边界

三文字子句不能拆成三条两文字子句而保持等价：`x∨y∨z` 在仅 x 真时成立，而 `(y∨z)` 不成立。

## 审稿检查

用单位子句及互斥条件测试取反映射与赋值方向，最终逐条验证原子句。对博客中的约束翻译分别证模型到图、图到模型。

## 区别与联系

通用 SAT 不存在由此直接导出的线性算法；这里充分性依赖逆否对应。
