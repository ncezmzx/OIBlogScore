此目录不是全部以 MIT 再授权。`upstream/cp-algorithms/` 的 47 个 `.md.txt` 是 **原样收录**，署名 **cp-algorithms contributors（含原文标注的 e-maxx 来源和各页作者）**，按原 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 许可；同目录附 [上游许可证全文](upstream/cp-algorithms/LICENSE.txt)。未改写文件内容、代码、作者标记或原有第三方声明；`.txt` 后缀只用于明确其为不可变原稿。原图、站点模板及其它附件未复制；链接、图像或宏以原站及固定提交为准，文件不是可离线渲染的站点镜像。`.gitattributes` 防止 Git 换行转换。命令 `source <id> --text` 先打印许可、署名信息、原地址、固定快照和逐页 Git 作者历史，再打印原稿。直接分享单篇时也应随附这些字段、保留源稿内的署名及许可，并遵守相同方式共享要求。

`providers.json` 记录各来源政策、SHA 和声明文档字节哈希。具体条目的 `authors: []` 表示未可靠枚举个人，不代表无作者；Git 材料保留 `history` 和 `permalink`。`import-policy.json` 是人工审查过的收录范围；`approved-verbatim.json` 是已批准复制的每个版本的内容哈希。站点许可标签不替代逐页例外核对。`trust: upstream-unreviewed` 表示 OIBlogScore 未独立验证其中的数学陈述，即使原文已收录。
