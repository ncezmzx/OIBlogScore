# 凸包优化：直线化与单调队列

## 问题模型

将 `F[i]=g(i)+min_j(m_j*x_i+b_j)` 中的合法历史决策变成直线；本专题讨论最小值、斜率严格递减（先处理重复斜率）且查询 x 非降。

## 算法原理

按交点顺序存下包络。若相邻三线的两个交点不递增，中间线无独占最优区间，移除；查询时看第二条是否不劣，不劣则永久弹掉队首。

## 成立条件

维护方向与 min/max 对应；重复斜率保留较低截距。查询位置非降才允许永久弹头；直线须在成为合法决策之后才插入。

## 关键不变量

队列保留未来查询范围内可能最优的直线，交点有序；在 x 处被右侧更小斜率线击败的高斜率线，在任何更大 x 不会反超。

## 证明路线

用两线差为一次式证明头删；用三个斜率的相邻交点序证明尾删。先推导原始 DP 展开式与候选域，对每个式子核对符号。

## 复杂度推导

每条线进队一次、出队最多一次，合计 O(L+Q)，单次插入仍可能线性。斜率单调但查询不单调时可保留包络并二分，查询 O(log L)。

## 错误与反例

插 `y=x` 与 `y=0`，先查 x=1 再查 x=−1：第一次弹掉 y=x 后，第二次错误得 0 而非 −1。

## 性质边界

单调性不来自斜率名词：前缀和含负数时可能非单调。交点用交叉乘避免浮点，但扩大类型前做减法同样会溢出。

## 审稿检查

抽取实际 m、b、x 序列和插入时机；用相等斜率、交点同坐标、负值和递减 x 检查代码，必要时对照 O(n²) 转移。

## 区别与联系

斜率或查询顺序不满足时，考虑 Li Chao；Slope Trick 维护凸分段线性函数本身，不是保存决策直线的别名。
