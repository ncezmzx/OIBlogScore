# 分治 DP：最优决策单调性

## 问题模型

固定一层 `F[j]=min_{k≤j}(G[k−1]+C(k,j))`，G 已算完。目标是缩小候选 k 的范围，而不改变转移。

## 算法原理

计算中点 j 的最优 k，左半只搜索至该 k，右半从该 k 起。并列按与证明一致的规则（如最左最优）。

## 成立条件

需证明在实际合法域中采用该平局规则得到非降最优下标。用 Monge 证明时，明确适用下标不等式和不可达项；限制竞争决策必须在交换比较的位置同时可行。

## 关键不变量

每个递归区间的候选上下界包含其全部列的指定最优决策；中点枚举还须与 k≤j 取交集。

## 证明路线

若声称 Monge，取 k1<k2、j1<j2，验证 `A(k1,j1)+A(k2,j2)≤A(k1,j2)+A(k2,j1)`。若最左最优在 j1 为 k2、j2 为 k1，最优性给反向和不等式；相等使 k1 也是 j1 最优，矛盾（需交叉项可行）。

## 复杂度推导

对 n 列各层候选区间总长 O(n)：子范围只在分界 k 重叠，累积额外长度不超过该层区间数。深度 O(log n)，每层转移 O(n T_C)；另计代价预处理及 DP 层数。

## 错误与反例

两决策两列成本为 `[[1,0],[0,1]]`，各列最优从决策 2 回到 1。只观察前几个样例不能保证单调；若仍剪枝会漏真实最优。

## 性质边界

分治优化与 Knuth 的双侧区间边界不同。固定层可并行搜索不代表原地计算依赖当前层时也能乱序递归。

## 审稿检查

给出实际 C 的 Monge 代数或直接单调证明，不接受只说“满足四边形不等式”；检查并列比较符、合法 k、无解列和移动窗口维护成本。

## 区别与联系

CHT 把候选转为直线，条件不是决策下标单调；CDQ 可处理先算左再传播的依赖，但不能代替本专题的最优范围证明。
