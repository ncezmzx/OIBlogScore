# 状态压缩：集合语义与子集枚举

## 问题模型

用 n 位集合记录已选顶点，例：从固定源到 v 且恰访问 S 的最短简单路 `F[S,v]`。明确重复使用和闭环的规则。

## 算法原理

将最后新增顶点 v 删去，从 `F[S\{v},u]+w(u,v)` 取最小。对任意子掩码 A 的枚举可用 `a=(a−1)&S`，需要显式处理 0。

## 成立条件

位数必须在移位类型可表示范围内，状态容量可分配；仅靠集合不足时保留所需的末端信息。保证扩展只添加尚未进入 S 的点。

## 关键不变量

每状态恰表示固定集合及端点的最优值；转移只从少一个元素的合法集合读取。缺边和不可达单独处理。

## 证明路线

对集合基数归纳，删末边得到完整且可复原的分解；计数时每条路径按末点/前驱分到唯一分支。子掩码枚举可视作把 S 的置位压成紧密整数后降序迭代。

## 复杂度推导

O(n2^n) 个状态各扫 n 个候选为 O(n²2^n)，空间 O(n2^n)。若枚举所有 S 及其子集 A，总数 `Σ C(n,k)2^k=3^n`，不是 O(2^n n)。

## 错误与反例

两条到同一个访问集合的路径若分别以 a、b 结尾，且只有 b 能接目标，按 `dp[S]` 保留较便宜的 a 会删掉可行解。枚举 a=0 后仍做 `(a−1)&S` 会跳回 S。

## 性质边界

压缩集合表示不等于减少状态个数；子集卷积或 SOS DP 依赖不同代数结构，不是任意枚举都可降到 n2^n。

## 审稿检查

检查基状态和是否需要回到起点、移位字面量、有向缺边、不可达哨兵；用 n≤5 穷举排列独立对照。

## 区别与联系

普通 DP 的语义证明仍是核心；此处新增的是集合编码和指数代价核算。
