# Fenwick：前缀与逆操作

## 问题模型

维护 1-based 可加量的点增量、前缀和；区间和通过两个前缀相减。下述区间修改只针对加法。

## 算法原理

`bit[i]` 保存 `(i-lowbit(i),i]`。查询通过减 lowbit 收集小块；修改通过加 lowbit 沿所有包含该点的块传播。

## 成立条件

下标必须大于 0；差分的区间撤销依赖逆元。若由前缀权值找第 k 个，权值非负且 k 在总量范围内。

## 关键不变量

每个节点的值始终等于其定义区间的和；查询已取区间互不相交，尚未取部分仍是前缀。

## 证明路线

从二进制最低置位解释查询清一位得到前一个边界；证明更新链正好覆盖所有含该点的节点，不漏不重。

## 复杂度推导

查询最多 popcount(i) 步，更新每次使最低置位上移，至多 O(log n) 步。数组空间 O(n)；逐点构建是 O(n log n)，不能称线性构建。

## 错误与反例

索引为 0 时 `i += i & -i` 不前进。对权 `[3,-5,4]`，前缀 `[3,-2,2]`，谓词“≥2”不是单调，不能做普通前缀二分。

## 性质边界

同一 Fenwick 更新规则不能把 sum 换成任意幺半群：一般区间 min 无法由两次前缀 min 反推出；单调更新的前缀 min 是不同接口。

## 审稿检查

检查 0/1 基转换与 `r+1`；若两棵树维护差分 d，要求推导前缀为 `(x+1) Σd_i - Σi*d_i`，并核对乘法类型。

## 区别与联系

线段树不需要用逆元做区间查询，可以处理有序聚合；两者复杂度相同不意味着可互换。
