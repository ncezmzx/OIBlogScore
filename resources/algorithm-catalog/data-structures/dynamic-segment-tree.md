# 动态开点线段树：隐式默认值

## 问题模型

固定巨大整数域 `[L,R)` 上的稀疏更新。未分配的节点代表一段默认数组，不代表不存在于问题域。

## 算法原理

只在需要修改的路径建节点，查询缺失分支时按区间长度计算默认摘要；若支持懒标记，需定义未建孩子如何继承父状态。

## 成立条件

确定域宽 U 和 `mid` 的安全求法，确保每次二分缩短区间。默认值与合并语义一致；加法懒标记不能在下传时丢失。

## 关键不变量

虚节点的逻辑摘要与显式建出的默认段相同；子节点创建后加上未下传的逻辑更新。

## 证明路线

把稀疏树视为满树的压缩表示：每个分配操作先恢复等价子树，再复用普通线段树的操作正确性。

## 复杂度推导

点更新最多访问和新增 O(log(U+1)) 节点，Q 次 O(Q log(U+1))；查询若实现无分配，不增长空间。区间或合并操作需另计实际分配。

## 错误与反例

默认全 0，整域加 1 后才创建左儿子；若把缺失分支直接当 0，单点查询为 0 而应为 1。

## 性质边界

离线压缩仅保序，不保距离。维护覆盖长度要保存真实坐标间距；不可直接用压缩下标差作长度。

## 审稿检查

读 query 对空结点和父懒标记的分支；列最大坐标差、节点上界、每节点字节。用全域更新后查空分支作对照。

## 区别与联系

与持久化共享树形但关注分配时机而非时间版本；离线坐标可知时可比较常规压缩实现。
