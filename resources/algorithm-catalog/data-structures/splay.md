# Splay：访问引理与旋转次序

## 问题模型

维护有序搜索树；一个键查找后将找到的（或最后访问的）节点旋至根。分析普通正权 Splay，不等于动态树的辅助树分析。

## 算法原理

父为根时一次 zig；同向父祖链先旋父再旋节点（zig-zig）；异向连续旋该节点（zig-zag）。旋转保持中序，按孩子到父的顺序重算摘要。

## 成立条件

明确访问不存在时的契约及是否把最后节点伸展。摊还不是任意旋转规则的属性；两步旋转不能由两次随意的 zig 替换。

## 关键不变量

中序键次序不变，悬挂子树仍在正确开区间；每次操作之后父子双向指针和聚合一致。

## 证明路线

设 rank(x)=log₂(子树节点权和)，势为各 rank 和。对 zig、zig-zig、zig-zag 分别比较改变的节点秩；双步利用两棵互斥子树大小和≤新根大小及对数凹性，得到一次伸展的摊还旋转数≤`3(rank(root)−rank(x))+1`（操作前秩）。各步秩差求和望远镜。

## 复杂度推导

单位权固定 n 时，上式 O(log n)；累计实际代价需加初势减终势。空树建表或动态插删须另外展开接合/拆分引起的势差。单次从长链末端查找可 Θ(n)。

## 错误与反例

键 1→2→3 的右链，访问 3 应先旋 2 再旋 3；总把 3 向上旋不是推荐的双步规则，不能套访问引理。另测旋转后原根的父指针不为垃圾值。

## 性质边界

仅证明单次 rotate 保持 BST 不足以证明摊还界；区间翻转的隐式 Splay 另需在旋转前从祖先下传标记。

## 审稿检查

绘制 p/g 与中间子树的指针轨迹，复核根更新和旋转次数；判断文中分析是否明确势、初态、操作类型。用空树和失败查找检查终止。

## 区别与联系

Treap 的期望依赖优先级随机模型；Splay 的保证来自确定性摊还，不能把摊还写成“随机树高”。
