# 虚树：关键点的 LCA 闭包

## 问题模型

静态有根树上多次给出关键点集；单次只保留这些点及必要分叉点，压缩其余链。

## 算法原理

对 k 个关键点去重并按 DFS 序排序，加入相邻点的 LCA，再排序，用栈连向最近的保留祖先。虚边可带原距离。

## 成立条件

LCA 与祖先判定必须使用同一根；要保留指定全局根时明确额外加入。业务转移需可沿压缩路径聚合。

## 关键不变量

栈中是当前处理位置的一条祖先链；弹出已经离开当前 DFS 子树的节点，栈顶是最近保留祖先。

## 证明路线

必要分叉点的不同儿子子树在 DFS 序相邻跨界处各提供一个关键点，因此相邻 LCA 覆盖分叉；其余删除点不改变保留点之间祖先关系。

## 复杂度推导

加入至多 k−1 个 LCA（非空、无额外根），O(k log k+k T_LCA) 构建，栈线性；每次清全树数组会另花 O(n)。

## 错误与反例

根有两个孩子且二者均关键。若只把相邻关键点直接连边，虚边不是祖先关系；若按虚边条数当原距离，压缩三级路径会错。

## 性质边界

不用每对关键点求 LCA；但若问题涉及所有未选点贡献，单纯删掉它们没有语义保证。

## 审稿检查

检查 k=0、重复点、根选取、虚边权定义、每轮状态清理与真实 `T_LCA`。用多分支和长链核对 DP。

## 区别与联系

重链剖分或倍增可为虚树提供 LCA；虚树是批次压缩，并非动态树数据结构。
