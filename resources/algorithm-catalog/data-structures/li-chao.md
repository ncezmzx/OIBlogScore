# Li Chao 树：单交性质

## 问题模型

插入直线，询问某离散坐标 x 的最小值。区间限定直线只在其定义段生效，是额外接口。

## 算法原理

节点中点保留两候选中较优者，把另一条送往可能反超的一侧；单点查询沿根叶取所有候选的最小值。

## 成立条件

端点和中点比较所用的函数族在有序离散域上的优劣关系至多换侧一次（直线满足）；比较必须无溢出，平局规则一致。

## 关键不变量

对任意 x，插入后根至 x 的路径仍包含在该点达到最优的候选。中点较劣的候选只能在一侧严格更优。

## 证明路线

在节点交换后证明被丢弃半边上保留函数不劣；另一半递归恢复原性质；查询取链上最优。

## 复杂度推导

坐标数 M，整体插入与查询各访问 O(log(M+1))；限定段插入拆 O(log M) 个覆盖节点，每处再做直线插入，O(log² M) 上界。

## 错误与反例

在 `{-2,-1,0,1,2}` 比较常量 0 与 `1-x²` 求 min：后者中点较差却两侧都更好；只往一边递归必漏。

## 性质边界

任意曲线或在整个域外推的有限线段都不满足默认契约。坐标压缩后数值应使用原 x，而非压缩编号。

## 审稿检查

检查比较符方向、mid/端点判断是否在交换前计算、空节点哨兵、乘积和截距的中间类型。测试同斜率、交点在域外及端点平局。

## 区别与联系

单调凸包可在额外插入与查询顺序条件下更快；Li Chao 不要求斜率单调，依赖离散域和单交条件。
