# 持久化线段树：版本与值域计数

## 问题模型

点更新后旧版本仍可查询；值域版本可表示各前缀的频数直方图，用来回答子数组第 k 小。

## 算法原理

复制被更新路径上的节点，并共享不变兄弟。对两个前缀根同步下降，用左子树频数之差决定方向。

## 成立条件

共享节点不再就地修改；频数差必须表示真实非负多重集。坐标压缩需保序，k 约定使用 1-based 且不超过总数。

## 关键不变量

根指针唯一确定可达树；每个版本节点摘要与其版本一致。下降时 k 是当前差分子树内部排名。

## 证明路线

按创建版本的时间归纳不可变性；再按值域区间长度归纳，左右区间不交且左侧值都更小，向右时扣除左频数。

## 复杂度推导

值域 σ，高 O(log(σ+1))；每次点更复制一条路径，非空初始树可耗 O(σ) 节点，空根方案可省。Q 次点更新另用 O(Q log(σ+1)) 节点，根数组 O(Q)。

## 错误与反例

从 `[1]` 的根插入 `2` 若原地递增共享根，旧版本计数错误。两条分叉版本 `[1]` 与 `[2]` 的任意做差可能出现负频数。

## 性质边界

并非所有查询都能做版本相减：max 不构成这里的可减直方图。区间懒更新的复制范围必须单独证明，不能套点更新节点数结论。

## 审稿检查

检查 build、clone、根赋值和每次写入；测试从旧版本分叉及旧根查询；估算节点池容量、引用在重新分配后的有效性。

## 区别与联系

动态开点只表示稀疏区间，不保证历史版本；持久化能够与开点结合，但两项证明独立。
