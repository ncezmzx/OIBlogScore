# 成本、随机与反例的证明义务

## Amortized Analysis

明确从什么初态、对哪些合法操作序列累计。势能法要求每种操作的 `实际成本 + 势能差` 有上界，且终止势能有统一下界；总实际成本 ≤ 摊还和 + 初始势能 − 终止势能。例：单调队列一次 push 可弹很多次，但每个元素至多被弹一次；不能写成单次最坏常数。报 `操作 / 代价 / 势差或收费对象 / 序列总界 / 单次反例`。

## Probabilistic Analysis

写明随机源、输入是否随种子适应、独立性以及保证的类型（期望、高概率、错误率）。期望线性不需独立，事件概率相乘需要独立；联合上界用和。固定素数 p 且随机基数时，只有非零差多项式才能套根数上界；固定基数的碰撞不具有该样本模型。报 `概率空间 / 随机变量 / 条件 / 上界推导 / 保证对象`。若用随机测试替代算法证明，结论降为有限证据。

## Counterexample Construction

固定被否定的精确全称命题，枚举许可的最小规模，先独立求真值再逐步走待审算法；若某次删边改变合法性，不算成功缩小。通过反驳须同时证合法、预期正确和行为不符。对证明缺口但找不到反例，只报未证或疑点。示例：固定一件 0/1 背包物品，容量 2、重量价值均为 1；正序更新两次使用同一件，错误答案 2。报 `命题 / 输入 / 合法性 / 独立答案 / 实际轨迹 / 搜索域与预算`。
