# 复杂度审查协议

先从规格提取原始规模、数值域、查询/测试总和及字长模型，再从实际实现登记各阶段的执行次数、每次成本、同时存活对象。附每项对应行及证据。不要把 O(n log n) 当作算法名称的属性。

## Recurrence Analysis

写出子问题个数和大小、底部代价及每个区间的非递归成本；归并 `T(n)=2T(n/2)+Θ(n)` 每层 Θ(n)，深度 Θ(log n)，得 Θ(n log n)。若每节点排序 Θ(m log m)，同层总约 `n(log n−d)`，求和 Θ(n log² n)。不规则 `T(n)=T(n−1)+Θ(n)` 逐层为 n、n−1 等，总 Θ(n²)，不能用平衡分治定理。核对 pivot、分隔点和空输入的实际规则。

## Divide and Conquer Complexity

列一张表 `层 / 总活跃规模 / 非递归工作 / 递归深度依据`。层内不重叠只保证数据量，不保证额外扫描：若每个子区间都清全局长度 n 的数组，Θ(n) 个非空节点会付 Θ(n²)。树重心分治每层节点总量≤n，子块减半；收集距离的单次 DFS 可深至 n，空间栈界不可照搬分治深度。

## CDQ Complexity

时间分治 N 事件至多 log N 层，左右两个列表合并后，每次插入和撤销各 O(log U)，询问 O(log U)，每层共 O(N log U)。总 O(N log N log U)，若独立排序每段，再加 O(N log² N)。使用保持有序的线性归并时，排序部分为 O(N log N)。若全域清 Fenwick，额外初始化按递归节点数乘 U；若每次逐点撤销，用实际更新次数而非排序次数。不把实现 A 的排序界与实现 B 的统计界拼成“统一”保证。

## 整体二分与多层结构

时间分桶版本每轮重放 T 个事件与 Q 次测试，约 log(T+2) 轮；初始化 DSU、扫描空桶和测试成本都要另计。按答案域递归时只要每个事件分到一个子问题，各层总 U+Q 记录；若计数树每次 log n，乘 log σ 深度。重链剖分路径跳过 O(log n) 条链，每条链区间查询 O(log n)，应乘成 O(log² n)，不能加成 O(log n)。预排序、前缀缓存或更快聚合须独立证明确实替换了内层成本。
