# 摊还与随机成本

## Amortized Complexity

把保证写成“任意合法长度 q 的操作序列，总成本≤…”，区别每次操作的最大值。动态数组在容量翻倍时某次 append 会复制 n 个元素，不能说最坏每次 O(1)。若允许缩容，检查阈值是否防止满载附近反复缩放。

## Potential Method

以双栈队列为例，令势能 Φ=2·输入栈大小，push/pop 单位成本。入队成本 1、势差 +2，摊还 3；出队若搬 k 个，搬运成本 2k 加弹出 1，势差 −2k，摊还 1。求和后减去终势加初势；若起始输入栈非空，初势不可忽略。对未覆盖的错误路径或重新初始化不能声称界成立。

## Aggregate Analysis

单调队列 n 次入队，每个下标至多出队一次，展开 while 的总次数≤n（每轮最多再有一次失败检查），总 O(n)。若某外循环又重新把同一元素加入其他队列，收费对象须是 `(队列,下标或入队实例)`，不能仍只按 n 个下标。

## Expected Complexity

写条件期望对什么固定。随机快速排序若每次对当前段均匀选主元，元素互异时，按排序秩 i,j，二者被比较概率为 `2/(j−i+1)`；对所有对求和 O(n log n)。最坏仍 Θ(n²)；全相等时，两路 partition 若每步只剔除一个主元，哪怕均匀随机也可能 Θ(n²)。

## Randomized Algorithms

区分随机影响运行时间（Las Vegas）和影响结果正确率（Monte Carlo）。对固定比较集合用并合界，无需独立；独立重复乘概率须证明种子独立且非自适应。若输入先获知固定哈希参数，不能套均匀随机碰撞界。报告写清输出保证、单次及累计错误概率、种子条件与对抗模型。
