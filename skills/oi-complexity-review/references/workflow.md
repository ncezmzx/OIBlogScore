# oi-complexity-review 执行协议

## 输入规格

声明界、规模变量、伪码/实现和运行限制；明确单位成本与是否多测。

## 工作流与资源

必读 [复杂度协议](protocol.md)，按声明类型加载 [摊还与随机](accounting.md) 和 [图与资源](resources.md)。

## 输出规格

分阶段代价、求和/递推、时间类型、内存峰值及带定位的结论。

## 失败处理

缺少实现时仅给伪码的条件化界；不替未读代码确认实现界。

## 验证过程

把状态重置、容器扩容、排序和共享数据重建单独计入总成本。一次最坏操作与一串操作的均摊界分别陈述；若势能证明只覆盖 chmin，不得转用于 add/chmax。

把所有循环、递归、初始化、排序和缓冲生命周期映回算式，复算最坏形态。

## 示例

全长 n 的等半递归若每节点重排 k 项，按层写 n(log n−d) 再求和；不要把单层排序上界乘错或套用归并排序。

CDQ 合并每次树操作 log U，每层 O(N) 次，深度 log N；若每节点排序，再加 O(N log² N)，写出为何不能省掉。
