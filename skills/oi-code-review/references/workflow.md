# oi-code-review 执行协议

## 输入规格

代码与行号、算法规格、输入范围、语言标准和环境；远端依赖不默认执行。

## 工作流与资源

核对 [C++ 语义](cpp-semantics.md) 与 [实现、资源和判级](cpp-implementation.md)。

## 输出规格

带分类和触发证据的静态结果，以及实际执行过或未执行的检查。

## 失败处理

缺编译规格时对拓展语义给条件结论，编译失败不自动归为算法错误。

## 验证过程

重走每个报告的合法触发路径，按 C++ 实际表达式类型核验，区分理论和环境假设。

## 示例

约束允许两个 50,000，`long long r=a*b;` 中 int 乘积超出 32 位 signed int；先在乘法操作数提升类型。
